# VERY 44기 임원진 웹 사용 가이드

작성 2026-08-04 · 대상: 44기 임원진 (디스코드 공유용)

## 로그인

- 어드민: **yonseivery.com/admin** (북마크 권장, 사이트 메뉴에는 없음)
- 학회원 포털: **members.yonseivery.com** (관리 메뉴는 임원진에게만 보임)
- 둘 다 구글 로그인이며, 임원진 명단에 등록된 본인 이메일 계정으로만 열립니다.
  로그인이 안 되면 학회장에게 등록 메일 주소를 확인해주세요.

## 어드민 권한 등급

어드민은 두 등급입니다. 왼쪽 메뉴 상단에 본인 등급이 표시됩니다.

- **학회장단**: 전권.
- **임원진**: 운영 실무. 아래 다섯 가지만 학회장단에게 요청하시면 됩니다.
  1. 지원자 합불 상태 변경과 결과 통보 발송
  2. 지원자·참관자 명단 반출 (엑셀·CSV 다운로드, 전화번호 일괄 복사)
  3. 접수 열기·닫기와 마감 시각 변경
  4. 학회원 자율 등록 신청 승인·거절
  5. 모든 영구 삭제 (지원서, 학회원, 알럼나이, 파트너, 후원자, 데모데이 회차)

지원자 명단과 첨부 열람, 세션·공지·출결, 학회원 정보 수정, 데모데이 운영,
파트너·후원자 관리는 임원진도 그대로 하실 수 있습니다. 버튼이 안 보인다면
고장이 아니라 등급 때문입니다.

## 리크루팅 (접수 기간 8/4 ~ 8/23 23:59)

- 지원자 확인: 어드민 > 리크루팅. 접수 시각, 연락처, 첨부 3종(지원서·계획서·작업물)이 한 행에 나옵니다. 첨부 링크는 1시간 유효라 만료되면 새로고침.
- 심사 상태: 행마다 드롭다운(검토 전 / 서류 합불 / 최종 합불) 선택 후 **저장**을 눌러야 반영됩니다.
- 결과 통보: 심사 상태가 다 저장되면 "결과 통보" 블록의 **서류/최종 결과 발송** 버튼으로 일괄 메일 발송. 이미 통보된 지원자에게는 다시 가지 않으니 중복 클릭 걱정은 없습니다.
- 엑셀 다운로드로 전체 명단을 받을 수 있습니다.

## 운영 규칙 (사고 예방, 필독)

1. **합불 상태 변경과 결과 발송은 반드시 2인 교차 확인 후 진행합니다.** 발송 전 엑셀을 받아 명단을 대조하세요. (타 학회에서 합격자를 불합격 처리해 사과문까지 간 사례가 있습니다)
2. **지원자 개인정보(연락처·첨부 파일)는 심사 목적 외 사용·공유 금지.** 단체 문자·메일을 보낼 일이 있으면 반드시 현재 기수 엑셀만 사용하세요.
3. 삭제 버튼은 지원서와 첨부를 영구 삭제합니다. 테스트 데이터 정리 외에는 누르지 않습니다.

## 학회원 등록 (44기는 /join 자율 등록)

- 학회원 본인이 **yonseivery.com/join** 에서 신청합니다 (구글 로그인이 되는 이메일 필수, 생년월일 포함 전 항목 필수).
- 승인: 어드민 > 학회원 > **자율 등록 신청**. 지원서 대조 배지("합격자 확인" / "이름 · 전화 일치" / "지원서에 없음")를 확인한 뒤 승인하세요. 승인하면 명단에 등록되고 그 이메일로 포털 로그인이 열립니다.
- **임원진 본인도 /join으로 들어옵니다.** 승인은 항상 "학회원"으로 되므로, 승인 후 어드민 > 학회원에서 그 행의 직책을 회장/부회장/임원진으로 바꿔야 멤버 목록의 임원 섹션에 표시됩니다.
- **리크루팅 화면의 "합격자 일괄 등록" 버튼은 44기에서 사용 금지.** 지원서의 옛 이메일(네이버 등) 22명이 명단에 되살아납니다. 등록은 /join 승인으로만 합니다.

## 학회원 포털 (44기 운영, 노션 대체)

- **세션 관리**: 새 세션 등록, 본문은 마크다운(# 제목, - 목록, 표, 링크). 초안으로 저장했다가 공개 전환 가능.
- **세션 자료 첨부**: 세션 편집 화면 아래 MATERIALS 구역에서 파일을 올리면 안내글 밑에 붙습니다. 저장 버튼과 무관하게 즉시 반영되고, 학회원은 원래 파일명 그대로 내려받습니다. PDF·PPT·한글·ZIP 등 50MB까지, 세션당 20개.
- **발표자료 제출 받기**: 세션 편집 화면의 "발표자료 제출"을 켜면 그 회차에 제출 칸이 열립니다. 마감 시각을 넣으면 이후 새 제출이 막힙니다(임원진도 예외 없음. 미뤄야 하면 시각을 고치세요). 제출물은 기본적으로 **임원진과 제출 본인에게만** 보이고, 발표가 끝나 서로 공유해도 될 때 "학회원 상호 공개"를 켭니다. 임원진 화면에는 미제출자 명단이 함께 뜹니다.
- **공지 관리**: 공지 등록·고정(PIN).
- **출결 관리**: 세션 선택 후 멤버별 출결·과제 미제출·비고 기록. 저장은 몇 번을 고쳐도 안전합니다. 폰에서는 카드형으로 바뀝니다.
- 학회원은 세션 자료 열람·내려받기, 발표자료 제출, 본인 출결 확인, 멤버 디렉토리, 자기소개 작성이 가능합니다. 43기 아카이브는 임원진만 볼 수 있습니다.
- **자기소개**는 43기 노션 형식입니다: 대표사진, MBTI, 잘하는 것 3가지, 좋아하는 것 3가지, 자유로운 TMI, 개인 포트폴리오. 멤버 페이지에서 서로 **댓글**을 남길 수 있습니다 (삭제는 본인과 임원진만 가능).
- 멤버 디렉토리는 학회장 · 부학회장 / 임원진 / 학회원 섹션으로 나뉘고, 카드 사진은 본인이 올린 대표사진이 우선입니다.
